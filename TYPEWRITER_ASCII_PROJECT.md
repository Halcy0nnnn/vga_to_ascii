# Standalone Typewriter ASCII Animation Project

## Project Vision

Transform the existing VGA-to-ASCII converter into a **plug-and-play, self-contained ASCII animation display** running on the Xilinx ML505 FPGA board. No external video input needed—the FPGA generates its own video signal and displays an animated typewriter effect.

### Animation Specification

**Concept**: Typewriter effect with "As Above, So Below"

**Animation Sequence**:
1. **WRITING PHASE** (~4.2 seconds)
   - Type the sentence "As Above, So Below" character by character
   - Speed: ~8–12 animation frames per character (12 frames chosen for clean divisor)
   - Blinking underscore cursor `_` follows the last character

2. **HOLDING PHASE** (3 seconds)
   - Full text displayed
   - Cursor continues blinking

3. **ERASING PHASE** (~4.2 seconds)
   - Clear characters in reverse, one by one
   - Cursor moves backward

4. **Loop**
   - Restart from WRITING PHASE

## Architecture: From VGA Pass-Through to Standalone Generator

### Current Project (VGA Pass-Through)
```
External VGA Signal (PC/Camera)
  ↓
[Capture VGA timing]
  ↓
[Average pixel blocks 8×16]
  ↓
[Compute brightness]
  ↓
[Map brightness → ASCII character]
  ↓
[Render character using font ROM]
  ↓
[Output to DVI monitor]
```

### Your New Project (Standalone Animation)
```
System Clock (33 MHz) → PLL → 50 MHz
  ↓
[Generate timing signals (HSYNC, VSYNC, X/Y)]
  ↓
[Animation State Machine]
  ↓
[Determine ASCII code for current pixel position]
  ↓
[Render character using font ROM]
  ↓
[Output to DVI monitor]
```

### Key Differences

| Aspect | Current | New Project |
|--------|---------|-------------|
| **Video source** | VGA-in from external device | Generated by FPGA PLL |
| **Timing** | Captured from VGA signal | `dvi_timing.v` (timing generator) |
| **Content** | Live pixel processing | ASCII string in ROM/registers |
| **Rendering** | Brightness-mapped characters | Direct character lookup + cursor |
| **Complexity** | Medium (capture + analyze) | **Simple** (timing + ROM lookup + state machine) |

## New Modules You Need to Write

### 1. `animation_engine.v` (Core Logic)
**Purpose**: Manage animation state and timing
**Responsibilities**:
- Track current animation phase (WRITING, HOLDING, ERASING)
- Track character position (0–21 for "As Above, So Below")
- Track frame counter (0–11 for character timing)
- Track blink counter (0–59 for ~1 Hz cursor blink)
- Output: current ASCII code, cursor visibility flag

**Inputs**:
- `clk` (50 MHz)
- `reset` (active high)

**Outputs**:
- `ascii_code` (8-bit) — current character to display
- `cursor_visible` (1-bit) — blinking cursor flag
- `char_position` (5-bit) — which character in string (0–21)

### 2. `char_compositor.v` (Pixel Mapping)
**Purpose**: Map screen pixel coordinates to ASCII characters and colors
**Responsibilities**:
- Take pixel (x, y) from `dvi_timing.v`
- Determine which character grid cell it belongs to
- Fetch ASCII code from animation engine for that cell
- Look up pixel in font ROM using `vga_font.v`
- Apply color (white on black, or your choice)
- Handle cursor rendering (underscore at end)

**Inputs**:
- `x_pixel`, `y_pixel` (from `dvi_timing.v`)
- `ascii_code`, `cursor_visible` (from `animation_engine.v`)
- `active_video` (from `dvi_timing.v`)

**Outputs**:
- `rgb` (12-bit: 4-bit R, 4-bit G, 4-bit B)

## Animation Parameters & Timing

| Parameter | Value | Notes |
|-----------|-------|-------|
| **System Clock** | 33 MHz | From ML505 board |
| **Pixel Clock** | 50 MHz | Generated by PLL |
| **Display Resolution** | 800×600 @ 60 Hz | Via `dvi_timing.v` |
| **Frame Rate** | 60 fps | → One frame every 16.67 µs |
| **Frames per Character** | 12 | 8–12 range; 12 chosen for clean divisor |
| **Time per Character** | 200 ms | 12 frames ÷ 60 fps = 0.2s |
| **WRITING Phase Duration** | ~4.2 seconds | 21 chars × 200 ms/char |
| **HOLDING Phase Duration** | 3 seconds | User spec |
| **ERASING Phase Duration** | ~4.2 seconds | Same as writing |
| **Full Animation Loop** | ~11.4 seconds | Write + Hold + Erase |
| **Cursor Blink Rate** | ~1 Hz | Toggle every 30 frames (on for 30, off for 30) |
| **Text Length** | 21 characters | "As Above, So Below" |
| **Character Grid Size** | 80×30 cells | Standard text grid in 800×600 |
| **Char Pixel Size** | 10 pixels wide × 20 pixels tall | Roughly centered on screen |
| **Text Position** | ~(X=300, Y=290) | Approximately center of display |

### Timing State Machine Pseudocode

```
Counter: frame_counter (0–59, resets every 60 frames)
Counter: char_frame_counter (0–11, resets every 12 frames within a phase)
Counter: char_position (0–21)
State: animation_phase (WRITING, HOLDING, or ERASING)

Every clock cycle:
  frame_counter += 1
  
  if frame_counter == 60:
    frame_counter = 0
    char_frame_counter += 1
    
    if char_frame_counter == 12:
      char_frame_counter = 0
      
      if animation_phase == WRITING:
        char_position += 1
        if char_position == 22:  // Wrote all 21 chars
          char_position = 21
          animation_phase = HOLDING
          hold_counter = 0
      
      else if animation_phase == ERASING:
        char_position -= 1
        if char_position == 0xFF:  // Underflow (went below 0)
          char_position = 0
          animation_phase = WRITING
  
  if animation_phase == HOLDING:
    hold_counter += 1
    if hold_counter == 180:  // 3 seconds × 60 fps
      hold_counter = 0
      animation_phase = ERASING
  
  // Cursor blink
  if frame_counter < 30:
    cursor_visible = 1
  else:
    cursor_visible = 0
```

## Key Design Decisions

1. **50 MHz Pixel Clock**: Sufficient for 800×600 @ 60 Hz (standard requirement is ~40 MHz)
2. **12 Frames per Character**: Divisor of 60 fps = exact frame boundaries, no fractional timing
3. **1 Hz Cursor Blink**: Human-perceivable (not too fast, not too slow); 30 frames on/off at 60 fps
4. **White on Black**: Simple, clear, high contrast; can add color later
5. **Center Text**: Roughly Y=290 (middle of 600px); X calculation based on char width
6. **No External Input Required**: Fully self-contained for plug-and-play operation

## Useful Reference: Existing Module Interfaces

### `dvi_timing.v` Output
```verilog
output [9:0] x;              // X pixel (0–799)
output [9:0] y;              // Y pixel (0–599)
output hsync;                // Active low HSYNC
output vsync;                // Active low VSYNC
output active_video;         // High when inside drawable area
```

### `vga_font.v` Interface
```verilog
input [7:0] ascii;           // ASCII code (0–255)
input [3:0] x;               // Column within character (0–15)
input [4:0] y;               // Row within character (0–19)
output pixel_out;            // 1 = white, 0 = black
```

### `dvi_module.v` Interface
```verilog
input [7:0] red, green, blue;  // RGB color
input hsync, vsync, de;        // Timing signals
output [11:0] dvi_d;           // DVI encoded data
```
